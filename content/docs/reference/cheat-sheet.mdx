## CLI setup

Point the Solana CLI at Gorbagana before you run balance, transfer, or deploy commands.

```bash
solana config set --url https://rpc.gorbagana.wtf
solana config get
```

Check the active wallet.

```bash
solana address
solana balance
```

Check another wallet.

```bash
solana balance WALLET_ADDRESS
```

## Transfers

Send a small transfer first when you are testing a new wallet or script.

```bash
solana transfer RECIPIENT_ADDRESS 0.001 \
  --url https://rpc.gorbagana.wtf
```

Confirm a submitted transaction.

```bash
solana confirm TRANSACTION_SIGNATURE -v \
  --url https://rpc.gorbagana.wtf
```

Open a transaction in the explorer.

## RPC checks

Use `getHealth` and `getSlot` before debugging client code.

```bash
curl https://rpc.gorbagana.wtf \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getHealth"}'
```

```bash
curl https://rpc.gorbagana.wtf \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
```

Create a JavaScript connection.

```ts
import { Connection } from "@solana/web3.js";

export const connection = new Connection(
  "https://rpc.gorbagana.wtf",
  "confirmed",
);
```

Common Solana CLI program lifecycle commands. See [Deploy programs](/build/deploy-programs) before you update, finalize, or close a production program.

Build and inspect local artifacts.

```bash
cargo build-sbf
solana address -k ./target/deploy/PROGRAM-keypair.json
solana rent PROGRAM_SIZE_BYTES
```

Deploy the program.

```bash
solana program deploy ./target/deploy/PROGRAM.so \
  --url https://rpc.gorbagana.wtf
```

Deploy with a specific Program ID.

```bash
solana program deploy ./target/deploy/PROGRAM.so \
  --program-id ./target/deploy/PROGRAM-keypair.json \
  --url https://rpc.gorbagana.wtf
```

Show deployed program metadata.

```bash
solana program show PROGRAM_ID \
  --url https://rpc.gorbagana.wtf
```

List programs controlled by the active wallet.

```bash
solana program show --programs \
  --url https://rpc.gorbagana.wtf
```

Download deployed program bytes.

```bash
solana program dump PROGRAM_ID ./downloaded_program.so \
  --url https://rpc.gorbagana.wtf
```

Extend a program before a larger update.

```bash
solana program extend PROGRAM_ID ADDITIONAL_BYTES \
  --url https://rpc.gorbagana.wtf
```

Transfer upgrade authority.

```bash
solana program set-upgrade-authority PROGRAM_ID \
  --new-upgrade-authority ./new-authority-keypair.json \
  --url https://rpc.gorbagana.wtf
```

Make the program immutable.

```bash
solana program set-upgrade-authority PROGRAM_ID \
  --final \
  --url https://rpc.gorbagana.wtf
```

Close a program.

```bash
solana program close PROGRAM_ID \
  --bypass-warning \
  --url https://rpc.gorbagana.wtf
```

<Callout type="warn" title="Final and close are permanent decisions">
  Make a program immutable only when you are sure it should never change again. Close a program only when you no longer need it.
</Callout>

## Anchor commands

Common Anchor workspace commands. See [Anchor projects](/build/anchor) for the full setup, Program ID alignment, IDL, and update flow.

| Task | Command |
| --- | --- |
| Check Anchor version | `anchor --version` |
| List workspace program IDs | `anchor keys list` |
| Sync `declare_id!` with program keypairs | `anchor keys sync` |
| Build programs and IDLs | `anchor build` |
| Deploy workspace programs | `anchor deploy --provider.cluster https://rpc.gorbagana.wtf` |
| Upgrade one program | `anchor upgrade ./target/deploy/PROGRAM.so --program-id PROGRAM_ID --provider.cluster https://rpc.gorbagana.wtf` |
| Fetch published IDL | `anchor idl fetch -o target/idl/verified.json PROGRAM_ID` |

## App snippets

Small helpers for frontend or script code.

Format native GOR from base units.

```ts
import { LAMPORTS_PER_SOL } from "@solana/web3.js";

export function formatGor(baseUnits: number) {
  return baseUnits / LAMPORTS_PER_SOL;
}
```

Build an explorer transaction URL.

```ts
export function explorerTxUrl(signature: string) {
  return `https://explorer.gorbagana.wtf/tx/${signature}`;
}
```
