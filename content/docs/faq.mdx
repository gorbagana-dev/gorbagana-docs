These answers cover the first questions people usually have when connecting wallets, scripts, and deployment tooling to Gorbagana.

<Accordions type="single">
<Accordion title="Is Gorbagana compatible with Solana tooling?">

Gorbagana uses an SVM developer path, so Solana-compatible clients, CLIs, and program tooling are the right starting point.

</Accordion>
<Accordion title="What wallet should I use?">

Use Backpack for wallet-based activity on Gorbagana. For deployments and scripts, use a local keypair with the Solana CLI.

</Accordion>
<Accordion title="Why does Backpack show a different balance than the explorer?">

Backpack can show stale state or a different selected network. Search the same wallet address in the [Explorer](/network/explorer). If the explorer shows the expected native GOR balance, reconnect Backpack, reload the app, and confirm the wallet uses Gorbagana RPC.

</Accordion>
<Accordion title="Can I use normal Solana wallet adapter code?">

Yes. Use the normal Solana wallet adapter provider flow, but set the connection endpoint to Gorbagana RPC. Wallet Standard wallets such as Backpack are detected automatically. See [Frontend apps](/build/frontend).

</Accordion>
<Accordion title="What RPC endpoint should I use?">

Use the public endpoint from [RPC setup](/network/rpc). For raw JSON-RPC request shapes, see [RPC methods](/reference/rpc).

For high-traffic apps, plan for dedicated infrastructure instead of relying only on a shared public endpoint.

</Accordion>
<Accordion title="How do I get native GOR?">

Use the [Bridge](/network/bridge) to move GOR from Solana to native GOR on Gorbagana.

</Accordion>
<Accordion title="What explorer should I use?">

Use the [Explorer](/network/explorer).

Search by transaction signature, wallet address, program address, or validator page.

</Accordion>
<Accordion title="Is there a devnet?">

These docs focus on the live Gorbagana network. Use small amounts when you test transactions or deployments.

</Accordion>
<Accordion title="Where should I report docs issues?">

Use the GitHub organization link in the docs sidebar or ask in Telegram.

</Accordion>
</Accordions>
