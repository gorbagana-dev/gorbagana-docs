GOR is the native token used for gas on Gorbagana.

| Field | Value |
| --- | --- |
| Native token | GOR |
| Decimals | `9` |
| Smallest unit | `1_000_000_000` base units per `1 GOR` |
| Solana token mint | `71Jvq4Epe2FCJ7JFSF7jLXdNk1Wy4Bhqd9iL6bEFELvg` |
| Bridge | `https://bridge.gorbagana.wtf` |

## Native GOR

Use native GOR on Gorbagana to pay transaction fees, deploy programs, and interact with apps.

## GOR on Solana

The Solana token mint represents GOR before or after bridging.
