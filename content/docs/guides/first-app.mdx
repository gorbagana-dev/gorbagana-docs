This guide creates a small TypeScript script that connects to Gorbagana, reads your wallet balance, sends a tiny GOR transfer, and prints an explorer link.

## What you build

This guide creates a script that:

- connects to Gorbagana RPC
- loads your local Solana CLI keypair
- reads native GOR balance
- sends `0.001 GOR` to a recipient
- prints the transaction signature and explorer URL

<Callout type="warn" title="Use a test amount">
  The example sends real native GOR on Gorbagana. Start with a tiny amount and verify the recipient address before running it.
</Callout>

## Create a project

Create a new folder and initialize a TypeScript script project.

```bash
mkdir gorbagana-first-app
cd gorbagana-first-app
npm init -y
```

## Prepare a funded keypair

The script uses your Solana CLI keypair by default.

```bash
solana config set --url https://rpc.gorbagana.wtf
solana address
solana balance
```

If the wallet has no native GOR, bridge to that address with the [Bridge](/docs/network/bridge).

## Write the script

Create `first-app.ts`.

```ts
import {
  Connection,
  Keypair,
  LAMPORTS_PER_SOL,
  PublicKey,
  SystemProgram,
  Transaction,
  sendAndConfirmTransaction,
} from "@solana/web3.js";
import { readFileSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";

const RPC_URL = "https://rpc.gorbagana.wtf";
const TRANSFER_AMOUNT_GOR = 0.001;

const recipientAddress = process.env.RECIPIENT_ADDRESS;

if (!recipientAddress) {
  throw new Error("Set RECIPIENT_ADDRESS before running the script.");
}

const keypairPath =
  process.env.SOLANA_KEYPAIR ??
  join(homedir(), ".config", "solana", "id.json");

const secretKey = Uint8Array.from(
  JSON.parse(readFileSync(keypairPath, "utf8")),
);

const payer = Keypair.fromSecretKey(secretKey);
const recipient = new PublicKey(recipientAddress);
const connection = new Connection(RPC_URL, "confirmed");

const balance = await connection.getBalance(payer.publicKey);
const lamports = Math.round(TRANSFER_AMOUNT_GOR * LAMPORTS_PER_SOL);

console.log("Wallet:", payer.publicKey.toBase58());
console.log("Balance:", balance / LAMPORTS_PER_SOL, "GOR");

if (balance <= lamports) {
  throw new Error("The wallet does not have enough native GOR.");
}

const transaction = new Transaction().add(
  SystemProgram.transfer({
    fromPubkey: payer.publicKey,
    toPubkey: recipient,
    lamports,
  }),
);

const signature = await sendAndConfirmTransaction(
  connection,
  transaction,
  [payer],
  { commitment: "confirmed" },
);

console.log("Signature:", signature);
console.log(`Explorer: https://explorer.gorbagana.wtf/tx/${signature}`);
```

## Run it

Set a recipient and run the script.

```bash
RECIPIENT_ADDRESS=RECIPIENT_ADDRESS npx tsx first-app.ts
```

On Windows PowerShell:

```powershell
$env:RECIPIENT_ADDRESS = "RECIPIENT_ADDRESS"
npx tsx first-app.ts
```

Expected output:

```txt
Wallet: WALLET_ADDRESS
Balance: 12.345 GOR
Signature: TRANSACTION_SIGNATURE
Explorer: https://explorer.gorbagana.wtf/tx/TRANSACTION_SIGNATURE
```

## Verify the result

Open the printed explorer link. Check:

- status is successful
- sender and recipient are correct
- amount is `0.001 GOR`
- fee is paid by the sender
